# Codex Skills

Personal Codex skill repository.

## Skills

- `write-requirement-doc`: Chinese product requirement document writing skill.

## Install

Use Codex skill installer with the GitHub directory URL:

```text
$skill-installer install https://github.com/<owner>/<repo>/tree/main/skills/write-requirement-doc
```

After installing, restart Codex or start a new session, then invoke:

```text
Use $write-requirement-doc to 按照我的需求文档标准，基于以下业务需求撰写一份专业需求说明书：
```
